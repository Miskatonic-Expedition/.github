# Contributing to Miskatonic Expedition

Thanks for your interest in contributing.

## Before you start

- Check existing issues and pull requests before opening a new one.
- For larger changes, open an issue first so the direction can be discussed.
- Follow the contribution and setup instructions in the repository you are
  contributing to.

## Issues

When reporting a bug, include:

- A clear description of the problem
- Steps to reproduce it
- Expected and actual behavior
- Relevant environment details, logs, or screenshots

When suggesting a feature, explain the use case and the problem it would solve.

## Pull requests

- Keep each pull request focused on one change.
- Update documentation when behavior or usage changes.
- Add or update tests when appropriate.
- Make sure existing checks pass before requesting review.
- Use a clear title and describe what changed and why.

By participating, you agree to follow the project's [Code of Conduct](./CODE_OF_CONDUCT.md).
